Asylum activity relative to population

Applications and outcomes per 100,000 residents, matched by country and year.

A country’s size changes how an application total should be read. This page divides reported asylum activity by the receiving country’s population in the same year, showing both events per 100,000 residents and the inverse, residents per recorded event.

Population comes from the World Bank’s SP.POP.TOTL indicator: annual midyear estimates. World Bank definition and sources. A missing population or asylum value remains unavailable; another year’s population is never substituted.

The main view uses person-reported records, so case counts covering an unknown number of people are excluded. The optional combined view retains the report’s original persons-plus-cases activity, but is exploratory and must not be read as a harmonised person-based comparison. Applications are events and can include repeat claims and appeals; these rates do not count unique residents, measure public-service costs, or estimate someone’s chance of asylum.

The six measures overlap: any protection already includes refugee status and other protection. Do not add all six rates together. Closures remain a distinct processing outcome, rather than being treated as refusals.

populationData=FileAttachment("data/population/comparison.json").json()

viewof populationYear=Inputs.select(Array.from({length:populationData.metadata.asylum_source.year_to_available-populationData.metadata.asylum_source.year_from+1},(_,i)=>populationData.metadata.asylum_source.year_from+i),{label:"Matched year",value:populationData.metadata.default_year,format:String})
viewof populationMode=Inputs.radio(new Map([["Person-reported records (comparable population basis)","P"],["All reported activity (persons + cases; exploratory)","combined"]]),{label:"Numerator coverage",value:"P"})
viewof populationMetric=Inputs.select(popCore.metrics,{label:"Trend and country-comparison measure",format:d=>d[1],value:popCore.metrics[0]})

populationSelected=populationRows.find(d=>d.year===populationYear)
populationMetricKey=populationMetric[0]+"_per_100k"
populationTable=popCore.metrics.map(([key,label])=>({measure:label,count:populationSelected[key],population:populationSelected.population,population_year:populationSelected.population_year,per_100k:populationSelected[key+"_per_100k"],residents_per_event:populationSelected["residents_per_"+key]}))
populationComparison=populationData.top20.map(iso=>({...popCore.countryYears(populationData,iso,populationMode).find(d=>d.year===populationYear),name:popCore.countryName(populationData.countries.find(c=>c.iso===iso)||{iso,name:iso})})).sort((a,b)=>(b[populationMetricKey]??-1)-(a[populationMetricKey]??-1))
{
  const note=document.createElement("p");note.className="explorer-status";
  note.textContent=populationCountry.name+" · "+populationYear+" population: "+(populationSelected.population?populationSelected.population.toLocaleString("en-GB"):"unavailable for this year")+". Applications, grants, refusals and closures

Per 100,000 residents = reported events ÷ same-year population × 100,000. Residents per event is the inverse ratio. Where a reported count is zero, the per-100,000 rate is zero, but residents per event is undefined rather than zero. Missing reports remain unavailable.

The comparison uses receiving-country population, not the population of each applicant’s country of origin. Rates are descriptive activity indicators, not measures of the proportion of residents who claimed asylum. Coverage, procedures, repeat applications, and changes in reporting units still matter. World Bank country/economy codes are matched exactly to receiving-country codes; unmatched historical or special codes remain unavailable rather than being reassigned.

These international activity measures include all reported procedural stages. The UK official-statistics comparison deliberately uses a narrower first-instance scope, so its counts can differ.
